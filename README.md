# Feetcode

An early React scaffold for a planned pattern-first DSA study platform.

**Public branch status:** introductory interface and application scaffold. Algorithm tracing, fuzzing, a judge, and a complete learning catalog are not implemented on this branch. More developed local work is separate and is not represented as a public release.

## Development

```sh
cd client
npm install
npm run dev
npm run build
npm run lint
```

Built with JavaScript, React, React Router and Vite. This repository is a secondary experiment, not a production study platform.
